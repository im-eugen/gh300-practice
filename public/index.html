    About this practice room

    A free, non-commercial study aid for the GitHub Copilot certification (exam GH-300). I developed it for my own exam practice and now share it so colleagues can practise too. It isn’t affiliated with, endorsed by or connected to GitHub, Microsoft, Pearson VUE or any employer. GitHub, Copilot and Microsoft are trademarks of their owners.

    Where the questions come from

    Every question was written from public sources only:

    • the official GH-300 study guide (skills measured as of 7 August 2026), which sets the topics and domain weights;
    • GitHub Docs, the GitHub Copilot Trust Center, the GitHub Blog and the Microsoft Learn training modules for GitHub Copilot.

    The questions were drafted with the help of an AI assistant (Claude, by Anthropic) and checked against the documentation they cite. Each explanation links to its source so you can verify the answer yourself.

    The question formats (single and multiple choice, dropdowns, yes/no statements and ordering steps) follow the item types Microsoft shows publicly in its exam sandbox.

    What this is not

    • It contains no questions copied or reconstructed from the live exam, and no material from exam dumps. Using real exam content would break the exam agreement every candidate accepts, and this app doesn’t do that.
    • It isn’t official. Scores here don’t predict your real score. The exam count of 65 questions and the 100-minute timer are estimates for practice.
    • It may contain mistakes, and Copilot changes quickly. If an answer here disagrees with the current documentation, the documentation is right.

    Your privacy

    • No account, no cookies, no analytics, no tracking and no ads.
    • The app makes no network requests after the page loads. Its Content Security Policy blocks every outside connection, which you can confirm in your browser’s developer tools.
    • Your attempts and most-missed questions are stored only in this browser’s local storage, on this device. They’re never sent anywhere, and nobody else, including whoever shared this link, can see them.
    • Like any website, the hosting provider (Cloudflare) handles standard technical data, such as your IP address, to deliver the page.
    • Source links open external sites (GitHub, Microsoft) that have their own privacy policies.

    Preparing for the real exam

    Use this alongside the official study guide, the Microsoft Learn learning paths GitHub Copilot Fundamentals Part 1 and Part 2, and hands-on time with Copilot.
